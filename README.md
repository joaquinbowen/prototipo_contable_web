# CONT MARJO · Web

Aplicación web de demostración para contribuyentes, contadores y superadministración.

## Requisitos

- Node.js LTS
- pnpm 10+

## Desarrollo

```powershell
pnpm install
pnpm dev
```

## Validación

```powershell
pnpm lint
pnpm build
```

Las operaciones de SRI, OCR, firma digital y persistencia son simulaciones locales; esta app no transmite documentos ni credenciales a esos servicios.
